# Al Manara Academy

Portfolio demonstration website for a fictional private school in **Abu Dhabi, UAE**.

Built with React, Vite, React Router, and Framer Motion — designed to show clients the quality of school / enterprise presentation sites.

## Pages

- Home
- About
- FAQ
- Contact

## Run locally

```bash
cd private-school
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Note

All names, contacts, and campus details are fictional and for portfolio use only.
