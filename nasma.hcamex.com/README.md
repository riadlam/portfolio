# Nasma Journeys

Premium travel atelier site for Nasma Journeys (نسمات للرحلات) — a Dubai-based agency crafting refined journeys worldwide.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (typically `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Stack

- React + TypeScript + Vite
- React Router
- Framer Motion
- EN / AR i18n via `LanguageContext`
